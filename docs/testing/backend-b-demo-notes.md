# 后端 B 演示与答辩说明

## 主流程演示

1. 卖家发布商品，接口返回 `pending`。
2. 使用已有已发布商品进行下单，订单返回 `reserved`。
3. 卖家确认订单，订单变为 `confirmed`。
4. 买家完成订单，订单变为 `completed`，商品同步变为 `sold`。
5. 买家提交评价，评价持久化成功。

讲解重点：

- 数据已从内存字典迁移到 SQLAlchemy/MySQL。
- 订单金额在创建时锁定。
- 完成订单和商品售出在同一事务内执行。

## 异常流程演示

### 重复下单

对已经存在有效订单的商品再次下单，接口返回统一 `409` 冲突响应，不产生重复订单。

### 越权操作

让非卖家尝试确认订单，接口返回统一 `403`；让非买家尝试完成或评价订单，同样返回 `403`。

### 非法状态

对已取消订单执行确认，或对未完成订单提交评价，接口返回可解释的 `409` 状态冲突。

## 稳定性说明

- 重复确认、重复取消、重复完成均为幂等操作。
- 同进程使用商品锁，MySQL 使用商品行锁，避免并发重复下单。
- 商品和订单常用查询已复核组合索引。
- 自动化回归同时覆盖后端 B 和后端 C，避免迁移影响其他模块。
