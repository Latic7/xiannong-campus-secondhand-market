# 后端 B 商品与订单状态机

## 适用前提

第一阶段登录、浏览、发布、下单等主链路已经可以联调。本文记录后续阶段补强后的状态约束和权限边界。

## 商品状态

| 当前状态 | 允许目标状态 | 说明 |
| --- | --- | --- |
| `draft` | `pending`、`removed` | 提交审核或放弃草稿 |
| `pending` | `published`、`removed` | 管理员审核通过或发布者撤回 |
| `published` | `removed`、`sold` | 发布者下架或交易完成 |
| `removed` | `pending` | 重新提交审核 |
| `sold` | 无 | 终态 |

补充规则：

- 商品创建后默认为 `pending`。
- 普通商品更新接口不能直接把商品改为 `published`。
- 商品存在 `reserved` 或 `confirmed` 订单时，禁止改价和下架。
- `sold` 商品禁止继续修改或下架。
- 重复下架已下架商品按幂等成功处理。

## 订单状态

| 动作 | 当前状态 | 目标状态 | 操作人 |
| --- | --- | --- | --- |
| 创建订单 | 商品为 `published` 且无有效订单 | `reserved` | 买家 |
| 卖家确认 | `reserved` | `confirmed` | 卖家 |
| 取消订单 | `reserved`、`confirmed` | `cancelled` | 买家或卖家 |
| 完成订单 | `confirmed` | `completed` | 买家 |
| 提交评价 | `completed` | 状态不变 | 买家 |

补充规则：

- `completed` 和 `cancelled` 为终态。
- 买家不能购买自己发布的商品。
- 订单创建时锁定商品价格，订单金额之后不再变化。
- 订单完成与商品变为 `sold` 在同一事务中完成。
- 订单详情仅买卖双方可访问。

## 错误语义

| 场景 | HTTP 状态码 |
| --- | --- |
| 参数或图片校验失败 | `400` |
| 未登录或令牌无效 | `401` |
| 越权操作 | `403` |
| 商品、订单或图片不存在 | `404` |
| 非法状态流转、重复下单、重复评价 | `409` |
