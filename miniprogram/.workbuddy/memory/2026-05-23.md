## 修复底部导航栏颜色不同步问题

**问题**：自定义 tab-bar 的文字颜色变化与用户交互行为不一致，点击切换 tab 后颜色可能跳回旧值。

**根因**：组件 `show()` 生命周期中调用 `getCurrentPages()` 存在时序竞争——页面切换过程中 `show()` 触发时页面栈可能还没更新，导致 `updateSelectedIndex()` 将 `selected` 设回旧值。

**修复**：微信官方推荐做法——每个 tab 页面在 `onShow` 中主动调用 `this.getTabBar().setData({ selected: N })` 同步选中状态：
- `pages/home/index.js`：新增 `onShow()` → `tabBar.setData({ selected: 0 })`
- `pages/post/index.js`：新增 `onShow()` → `tabBar.setData({ selected: 1 })`
- `pages/user/index.js`：在已有的 `onShow()` 中追加 → `tabBar.setData({ selected: 2 })`
- `custom-tab-bar/index.js`：移除不可靠的 `show()` 生命周期自动检测

- `pages/home/index.wxml`：推荐商品区新增 3 张横向骨架卡片（`recommend-skeleton`），与真实 `recommend-item` 尺寸一致（300rpx宽，图片300×300 + 标题 + 价格），通过 `wx:if="{{loading}}"` 切换
- `pages/home/index.wxml`：移除最新发布区 `loading-state` 的 `message` 属性，骨架屏 shimmer 动画本身已充分传达加载状态
- `pages/home/index.wxss`：新增推荐区骨架样式 + `@keyframes shimmer` 动画

## 修复骨架屏不可见（请求太快/失败导致一闪而过）

**问题**：骨架屏 WXML 逻辑正确但用户看不到——API 请求失败或返回空数据时 `loading` 瞬间变 `false`，骨架屏来不及渲染。

**修复**：
- `pages/home/index.js`：`loadData()` 中改用 `Promise.allSettled` 防止单请求失败阻塞另一请求；追加 800ms 最小加载时长，确保骨架屏至少可见 800ms
- `pages/list/index.js`：`loadData()` 中追加 600ms 最小加载时长
- `pages/home/index.wxml`：推荐商品区 `wx:else` 改为 `wx:elif="{{recommends.length > 0}}"`，追加空状态分支 `wx:elif="{{!loading && recommends.length === 0}}"`，避免加载完成后展示空白 scroll-view

## 优化列表页 List

**改动范围**：`pages/list/index.*`（WXML/WXSS/JS 三文件全部重写）

**布局变化**：
- 搜索栏：搜索框 + 圆形筛选按钮（☰/✕状态切换），不再用文字"筛选"按钮
- 已选筛选标签：新增 `active-tags` 横滚条，每个激活筛选显示为可点✕移除的 chip，右侧"清除全部"红色文字按钮

**JS 逻辑变化**：
- 新增 `computeActiveTags()`：根据 keyword/categoryId/priceMin-Max 动态生成 `activeTags[]`

- 统一 `reload()` 方法：`page=1, products=[], hasMore=true` + `computeActiveTags()` + `loadData()`

## 全量图标升级（emoji → SVG 轮廓图标）

**问题**：全平台大量使用 emoji 作为功能图标（📚📱🏠👤❤️⭐等），跨平台渲染不一致，感知粗糙，与毛玻璃卡片/shimmer动画等精致组件不匹配。

**方案**：统一替换为 28 个自定义 SVG 轮廓图标（温润线条风：1.8px统一描边、圆角端点、24×24标准网格），存储于 `assets/icons/`。

**Phase 1 — 首页分类图标（5个）**：
- `pages/home/index.js`：categories 数组改为 iconPath + 对应品牌色 bgColor（书籍#6366F1、数码#F59E0B、生活#10B981、服饰#EC4899、其他#6B7280）
- `pages/home/index.wxml`：`<text>{{item.icon}}</text>` → `<image class="category-icon-img" src="{{item.iconPath}}"/>`
- 图标：book/phone/lamp/shirt/dots（白色版本，在品牌色圆底上显示）

**Phase 2 — Tab Bar + 搜索（4个文件）**：
- `custom-tab-bar/index.*`：data 中 emoji 替换为 iconPath/iconPathActive 双态路径（home-gray/home-active、user-gray/user-active）
- WXML 改为 `<image>` 根据 `selected` 切换；WXSS 用 tab-icon-img 替代 tab-icon
- `pages/home/index.*`：搜索栏🔍 → search.svg（40×40rpx，opacity:0.5）

**Phase 3 — 用户中心 + 详情页（8个文件）**：
- **用户中心**：头像占位👤→user.svg、信誉⭐→star.svg、菜单📦❤️📋ℹ️→package/heart/clipboard/info.svg
- **详情页**：错误😵→warning.svg、元信息📦✨📍→package/star/pin.svg、统计👁❤🕐→eye/heart/clock.svg、收藏❤️/🤍→heart-filled/heart.svg、举报⚠️→warning.svg、信誉⭐→star.svg
- 所有图标包装为 `<image>` + 配套类名（`meta-icon-img`/`stat-icon-img`/`action-icon-img`等），保持语义清晰
